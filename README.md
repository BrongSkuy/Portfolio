## 🌟 Tinjauan Singkat
Website portofolio ini menampilkan rekayasa sistem, proyek aplikasi nyata, sertifikasi nasional, dan CV resmi (format Visual & ATS). Mengadopsi estetika desain minimalis, hangat, dan terstruktur dengan gaya editorial khas **Claude AI**.

## 🛠️ Tech Stack & Ekosistem
- **Frontend Architecture:** Semantic HTML5, Vanilla CSS3 (Custom Design System & Tokens), Modern JavaScript (ES6+).
- **Styling System:** Warm Editorial Palette (Warm Ivory, Terracotta Accent `#C96442`, Deep Charcoal `#1F1E1B`), Newsreader & Plus Jakarta Sans typography.
- **Workflow & Tooling:** Antigravity IDE, Vibe Coding Architecture, Git/GitHub.
- **Documents & Export Engine:** Puppeteer (A4 Exact PDF & High-Res Render), ATS-Optimized HTML/CSS.
